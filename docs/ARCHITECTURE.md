# 喵记（DailyM）架构

本文描述本目录中的 Android 客户端源码。源码版本与已发布安装包的区别见 [验证记录](VERIFICATION.md)。项目包含一个 `:app` 模块，使用 package 划分代码边界。

应用默认及中文显示名称为“喵记”，英文为“DailyM”。包名 `com.percontext.community`、namespace `com.percontext.app`、数据库文件 `percontext.db` 和公共录音目录保留原有标识；显示名称变化不迁移用户数据。

## 代码边界

下表目录均相对于 `app/src/main/java/com/percontext/app/`。

| 目录 | 职责 |
|---|---|
| `core` | 音频解码、重采样、播放和格式化 |
| `domain` | 录音、转写、每日回顾模型与用例，以及外观设置契约 |
| `data` | Room、文件存储、SenseVoice、模型 HTTP 客户端和加密设置 |
| `feature` | Compose 页面和 ViewModel |
| `service` | 录音前台服务、转写与回顾后台任务 |
| `ui` | 六组昼夜配色、主题提供器与共享界面组件 |

`AppContainer` 组装功能网关、仓库、Provider 和后台任务；页面与 ViewModel 通过功能接口调用业务逻辑，不直接操作数据库、录音器或 HTTP 客户端。SenseVoice 和 LLM 执行依赖按需创建，未配置云端模型不阻断本地录音、播放和转写。

## 录音与转写

用户可见操作启动麦克风前台服务。Release 使用 `MediaRecorder` 写入单声道 AAC/M4A；Debug 在 Android 8.0 及以上使用 `AudioRecord`、AAC 编码器和 M4A 封装器，提供输入音量数据。两个录音路径的设备验证不能互相替代。

录音先完成音频发布，再登记 Room Record。Android 10 及以上通过 MediaStore 写入公共 `Download/PerContext/Recordings`，旧系统使用同名公共目录。发布成功但数据库登记失败时，文件保留，当前没有自动补建时间线的扫描流程。

转写由用户手动触发，通过按 Record 唯一的 WorkManager 任务执行。入队失败记为 `FAILED`；执行中取消恢复 `NOT_REQUESTED` 并传播取消。首次成功 Transcript 与时间片段作为不可覆盖快照保存；成功记录不能通过再次转写覆盖原文，失败任务可以手动重试。

后台任务将原始音频流式解码、降混和重采样为 16 kHz 单声道 PCM，按 30 秒窗口识别，不产生持久化转码副本。进程内最多一个 ASR session；录音处于启动、进行或停止保存阶段时，不启动新的 ASR session。该闸门不取消已经执行中的识别。

APK 内置固定的 SenseVoiceSmall INT8 模型。首次转写从资产复制到应用私有临时目录，校验长度及 SHA-256 后原子发布；每次创建原生识别器前重新校验。缺失或损坏的安装副本由 APK 资产重新准备，准备失败只使转写失败，不删除原始音频。Release 继续启用 R8 和资源收缩；[JNI 保留规则](../app/proguard-rules.pro) 保持 sherpa-onnx 类及成员名称，避免原生初始化时找不到配置字段。

## 每日回顾

用户选择设备时区中的一个自然日，手动生成或刷新 DailyContext。输入包含该日已保存的完整 Transcript，按录音时间排序，附带日期、时区、录音时刻和 `R1` 等请求内来源编号；不发送原音频、ASR 时间片段或其他日期的数据库内容。

每日回顾通过带联网约束、按日期唯一的 WorkManager 任务执行。离线发起的任务可在恢复网络后于后台发送。排队时只保存日期和时区，执行时重新读取来源及当时的模型配置；它不保存入队时来源正文或模型设置的不可变快照。来源变化确认发生在用户发起刷新、任务入队之前。

输出为 `daily_context.v1`，包含非空 `title`、`summary`，以及字符串数组 `topics`、`ideas`、`questions`、`decisions`、`todos`。解析器拒绝缺字段、类型错误、空字符串元素和非 JSON 正文，忽略额外字段，再保存规范化结构。结构校验不验证语义忠实度；提示词要求保留事实和确定程度，不推测用户动机、不把假设升级成决定。

同一日期只保留一个当前结果，日期字符串是主键，时区为独立字段。切换时区后来源按新时区归日，已有正文不会自动重生成。刷新前发现输入指纹变化时要求用户确认已备份；成功后替换正文，失败或取消保留上一次成功正文并更新任务状态。保存内容同时记录来源关系、输入指纹、Schema、Provider、模型和生成时间。

## 数据位置与生命周期

| 数据 | 位置 | 删除与卸载后果 |
|---|---|---|
| 原始 M4A | 公共 `Download/PerContext/Recordings` | 卸载保留；用户或有权限的外部应用仍可删除，文件未加密 |
| Record、Transcript、时间片段、DailyContext、来源关系 | 应用私有 Room 数据库，Schema v4 | 卸载清除；重装不自动导入旧音频 |
| API Key | Keystore AES-GCM 保护的私有设置密文 | 清除本机 Key 不撤销服务商端 Key；卸载清除 |
| 普通模型配置、外观、已安装模型 | 应用私有设置或文件目录 | 卸载清除；Android 备份与设备迁移规则排除应用数据 |

删除 Record 前先请求取消对应的唯一转写任务，等待取消操作返回后删除数据库行，最后尽力删除受管音频；这不等同于等待 Worker 完全退出。数据库删除失败时不操作文件；文件删除失败不会恢复已删除的数据库行。数据库级联删除对应 Transcript、时间片段和回顾来源关系，已生成 DailyContext 正文保留。来源删除后无法从剩余关联或输入指纹重建完整原文；当天录音列表展示现存记录，不是旧回顾的完整输入快照。

## 模型设置与网络边界

模型设置包含 DeepSeek 预设或用户自定义的 HTTPS 地址、模型名称与 API Key。自定义地址拒绝账号信息、查询参数、片段和非法端口；支持 Base URL 或以 `/chat/completions` 结尾的完整地址，统一规范化后请求。地址和模型名保存在 `llm_settings` DataStore，Key 经 Android Keystore AES-GCM 加密后保存。网络调用从同一份设置快照取得地址和 Key；更换自定义地址必须提供新 Key。客户端使用系统 TLS 信任和主机名验证，并拒绝重定向。

兼容范围为非流式 OpenAI Chat Completions 和 JSON Output：请求发送 `response_format={"type":"json_object"}`，响应须包含 `choices[0].message.content` 且 `finish_reason` 为 `stop`。DeepSeek 的思考参数只用于其预设分支，不发送给所有自定义服务。生成时转写会发送给所选模型服务，其数据留存由服务商决定。

本仓库只包含客户端，不提供账号、激活发码或托管模型服务。真实配置、模型源、应用数据和签名材料由 Git 忽略；固定模型来源、哈希及第三方许可进入构建约束。

## 外观与页面生命周期

外观设置使用独立的 `appearance_settings` DataStore，保存主题和显示模式两个稳定字符串值。`AppearanceViewModel` 在写入成功、仓库流发出新值后更新外观；单项写入保留另一项，未知值分别回退到晴空奶白和跟随系统。它不读写模型服务的 DataStore 或 API Key。

`MainActivity` 根据保存的外观与系统昼夜状态选择调色板，加载设置并应用外观后才允许绘制首帧，同时更新系统栏图标明暗。`PerContextTheme` 提供 Material 色彩角色及录音卡、皮蛋平台等扩展颜色；已有颜色属性通过组合环境读取当前主题。录音卡改用主题色绘制底部波纹，避免浅色位图覆盖夜间底色。

记录页和回顾页共用 `DailyPageScaffold`：页面左右留白 20 dp、顶距 8 dp，页头与设置触控框均为 48 dp，主面板与页头间距为 10 dp。主面板共用 30 dp 圆角、1 dp 边线及主题的 hero 表面；日历文字使用与该表面配对的 heroInk/heroMuted。记录主面板保留波浪和录音按钮，移除偏移背板；回顾的区段标签和选中日期位于皮蛋下方。

共享面板的自然内容高度至少为 350 dp，并按当前字体的行高、六周日历和录音控件需要的空间计算。小屏或大字体下，外框使用可用视口高度，内部内容维持自然高度并可滚动，不压缩六周日期或通过测量回写改变下一帧尺寸。下方列表与日期详情使用各自有界的 LazyColumn；页头、主面板外框和皮蛋平台不随这些列表滚动。`SaveableStateHolder` 保留切页前的面板及列表滚动状态，选月、选日仍由 ReviewViewModel 管理。

`PidanPerch` 将原生矢量分为身体、尾巴、头部和爪子四层，在两页共用的 40 dp 容器内保持相同平台位置。身体与头部按 4 秒周期呼吸、点头，尾巴每 8 秒摆动一次，爪子与平台固定。动画只在页面处于前台时运行，尊重 Compose 动画时长设置；记录页在录音状态下暂停皮蛋动画，回顾页未按录音状态暂停。

## 当前边界与验证缺口

当前没有全文搜索、跨日总结、原文修订、完整导出恢复、云同步或自动转写与自动回顾。系统进程中断后的录音登记修复、任务状态对账及重装导入也没有完整恢复流程。公共音频保留不能替代数据库备份。

设备验证覆盖的版本、构建类型和机型见 [验证记录](VERIFICATION.md)。模拟器界面测试不证明真实麦克风、离线模型推理、厂商后台限制或其他自定义模型服务通过；Release JNI 修复须检查实际启用混淆的安装包。
